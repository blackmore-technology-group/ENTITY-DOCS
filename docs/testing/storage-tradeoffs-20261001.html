Storage tradeoff suite

Three fresh, video-recorded tests answer developer objections that a single compression percentage cannot: static compression, exact content deduplication, and archive-vs-live-store behavior.

Bottom line: ENTITY does not beat conventional compressors at static archive size in these tests, and SQLite is faster for indexed lookup in the live-store microbenchmark. ENTITY advantages appear in reusable structured facts, exact duplicate content, compact graph representations, and incremental/provenance-bearing state changes. Treat each result within its stated baseline.

17A — Conventional compression baseline

The same 5,000-record datasets were serialized as canonical NDJSON and compressed losslessly. All compressed streams were decompressed byte-for-byte before PASS. Smaller bytes alone do not imply equivalent query/update semantics.
