Campaign

Seven bounded tests.

INP-01 / INP-02

Installation, persistent pseudonymous node identity and two-device exchange.

INP-03 / INP-04

Three-device lineage preservation and deliberate object/hash tamper rejection.

INP-05 / INP-06 / INP-07

Restart/recovery, offline envelope handoff and cross-platform exchange.

Evidence

Operator independence is recorded, not assumed.

BTG_CONTROLLED

BTG controls every endpoint.

EXTERNAL_REPRODUCTION

An unrelated operator reproduces the published test.

INDEPENDENT_MULTI_OPERATOR

Different unrelated operators control different endpoints in the exchange.

Claim boundary: a PASS establishes the bounded transport/hash/lineage behavior tested. It does not automatically establish full ENTITY conformance, external-world truth, legal ownership, monetary value, payment, certification or endorsement.
