# ENTITY Exchange Protocol v3 Conformance Vectors

Status: RELEASED / BTG INTERNAL QUALIFIED

Each vector is a raw EEP record body. Validation is two-layered: Draft 2020-12 JSON Schema validates exact shape and primitive types; canonical signed-wire rules additionally enforce deterministic representations and cross-field invariants that JSON Schema cannot express (for example lexicographic unique rights actions, total revenue basis points, and expiry-after-creation). Signature verification is tested separately by the executable EEP campaigns.
