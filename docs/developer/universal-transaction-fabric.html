Universal Transaction Fabric

Reference target: this page is grounded to the immutable v3.4.3 release implementation, not moving main.

The Universal Transaction Fabric is the common state model underneath ENTITY's authority, rights and economic system. It represents persistent governed objects, explicit delegated authority, machine-readable rights, attributable events, provenance, attestations and value without allowing custody, hosting, AI output or market infrastructure to silently become the authority root.

ENTITY → AUTHORITY → RIGHT → EVENT → VALUE

Five primitives

PrimitiveRole
ENTITYPersistent governed actor or object: people, organizations, AI agents, datasets, software, models, APIs, devices, financial instruments, physical assets and more.
AUTHORITYWho may ACT, SIGN, ACCESS_DATA, EXECUTE, PURCHASE, LICENSE, SETTLE, PUBLISH, RESOLVE, DELEGATE or CONTROL, with explicit scope and time bounds.
RIGHTWhat may be INSPECTed, READ, COPYied, DERIVEd, TRAINed on, INFERred from, EXECUTEd, MODIFYied, REDISTRIBUTEd, COMMERCIALIZEd, CONTROLled or TRANSFERred.
EVENTWhat occurred: an authorized action, usage event, provenance edge, market action, evidence event or other governed transition.
VALUEEconomic state from POTENTIAL and OFFER through CONTRACTED, ACCRUED, SETTLED and REALIZED.

Governed objects

The fabric can register governed objects with controller identity, object class, content hash and descriptor state. Object registration establishes the protocol object and its controller; it does not automatically establish legal ownership of an external asset.

Authority and rights remain separate

Delegated authority

A grantor can delegate defined actions to a grantee for a subject, scope and time interval. Revocation changes permission without replacing the underlying identity.

Explicit rights

A controller can grant bounded rights over an object, including economic terms and purpose/jurisdiction constraints. Access remains explicitly different from ownership.

Provenance without ownership inference

Provenance edges connect parent and child objects with relation type, evidence and optional contribution basis points. The graph is acyclic and the implementation explicitly preserves provenance_is_not_ownership. A causal or contribution relation therefore remains evidence about history rather than an automatic title/royalty claim.

Events and economic consequence

Material state transitions can bind actor, subject references, authority, right, payload hash and replay-resistant nonce. Value records separately describe the supported economic state. This allows an action to be technically valid while its monetary consequence remains merely potential, contracted, accrued or awaiting independently verified settlement.

How the fabric becomes a market

GOVERNED OBJECT → RIGHT → INSTRUMENT → VENUE → ORDER / RFQ / AUCTION → TRADE → CLEARING → ENTITLEMENT → USAGE → VALUE

The Exchange Protocol builds market mechanics on top of the fabric instead of inventing a separate trust model. A venue verifies participant authority/rights; it does not become the issuer of those rights merely because it hosts the exchange.

Transaction invariants

  • Actor identity does not imply authority.
  • Authority does not imply every right.
  • Access does not imply ownership.
  • Provenance does not imply legal title or royalty.
  • AI reasoning does not mint authority.
  • Signed intent must be replay-resistant.
  • Scarce entitlements must not be double-spent/transferred concurrently.
  • Execution does not prove external payment.
  • Settlement evidence must come through the required authorized verification boundary.
  • Recovery must preserve existing authority/rights without manufacturing privilege.

Real-world lineage

Vector #26501 / PR #26504 and Memnox #46 / PR #86 are examples of external events entering ENTITY as accepted contribution lineage. Their contributor, exact change-set, review/CI, upstream acceptance, rights context and economic state remain attributable; both correctly remain pro bono with USD 0 realized cash rather than being promoted into fictional paid transactions.
