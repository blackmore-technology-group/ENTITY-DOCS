Economic participation

Derivative Participation

Derivative participation links an upstream contribution to a downstream commercial consequence when explicit terms say that contribution participates economically.

Required chain

source DCO/right → authorized use → derivative output → commercial event → evidence of contribution/term → allocation → settlement

Lineage alone is not enough. The system should be able to show which signed term created the participation and what event triggered it.

Multiple contributors

Where several inputs contribute, the allocation method must be defined or evidenced. ENTITY should record zero or unknown contribution weight rather than inventing a percentage when none is justified.

AI/data use

The same rule applies to training data, model inputs and other derived outputs: provenance can be recorded broadly, while monetary participation exists only where explicit rights/terms support it.
