# BTG — Public Documentation and Adoption Portal

Edition 0.3 — 20 October 2026. Docs-only public site using the official user-supplied BTG brand icon. Includes the original 17 explanatory sections and five adoption briefings (public, individual, institutional, government, publication policy).

## Ownership boundaries

This repository path contains **public documentation only**. It does not contain issuer registries, ticker pages, instrument listing implementation, trading engines, public settlement feeds, or private Exchange source. Those are designed and maintained by separate engineering teams and are explicitly not altered by this publication.

## Safe publication state

Development and consultation draft. Unverified operating capability, regulator authorizations or commercial income must never be stated as fact. Public releases require BTG's publication and counsel review. Copyright © 2026 Blackmore Technology Group Limited, all rights reserved. The logo was supplied by BTG and is not an open-source asset.

## Deployment

All site links are relative. Host the contents under an independent GitHub Pages repository or a prefix on an existing BTG documentation Pages site. Move paths together to preserve relative navigation. Do not grant site CI privileged access to any private BTG backend.

## Expanded global adoption

The 4 region/global guides are documentation-only: Global Adoption Framework, Applications Across Regions, Country and Region Readiness Worksheet, International Partnership Programme. These are public consultation drafts and do not make any country-specific legal/operational claims. No investor instrument or ledger publication is in scope.
