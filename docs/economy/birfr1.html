DCO-000001 — BIRFR-1

Blackmore Industrial Robotics Failure & Recovery Dataset is a BTG-originated multimodal synthetic robotics corpus built around one training unit: normal execution → failure → recovery.

Qualified v0.1.0: 100,000 episodes · 20 failure families · 25 task families · 5 embodiment classes · 100 multimodal shards · 0 orders · 0 trades · 0 market marks.

Episode structure

Episode classCount

Failure-only30,000

Multimodal content

Each episode is indexed against robot state/action telemetry and recovery annotations, including RGB, depth, wrist RGB, joint position/velocity/torque, end-effector pose, gripper state, force/torque, robot actions, natural-language task, task phase, failure class/timestamp, root cause, recovery strategy/result and safety/near-miss flags.

Failure ontology

The 20 qualified failure families include grasp slip, missed/partial grasp, object displacement, collision/near collision, dropped object, orientation/alignment/insertion failures, excess/insufficient force, blocked motion, joint-limit approach, target occlusion, wrong-object selection, tool misalignment, trajectory deviation, stalled task and failed recovery.

The benchmark isolates unknown-failure and cross-embodiment performance rather than reducing evaluation to a single terminal success rate.

Cross-embodiment structure

TASK INTENT → FAILURE STATE → CORRECTIVE INTENT → RECOVERY RESULT

Those semantic fields are kept separate from embodiment-specific DOF, joint masks, commands and end-effector state so the corpus is not bound to one robot morphology.

Fidelity boundary

v0.1.0 is real, but it is not being overstated. The RGB/depth/wrist snapshots are compact 16×16 procedural synthetic imagery. They are actual BTG-generated asset bytes and qualify the multimodal pipeline, but they are not claimed to be photorealistic or equivalent to factory camera captures.

Later BIRFR versions can add high-resolution physics/rendered simulation, real RGB-D and force/torque captures, additional embodiments and contributed data while preserving the immutable v0.1.0 root.

Why the asset exists

Modern recovery research increasingly treats off-nominal intermediate states and recovery as a separate evaluation problem. BIRFR-1 is Blackmore's own asset response to that gap: a corpus and benchmark intended to support failure detection, classification, prediction and recovery rather than successful demonstrations alone.
