Built-in domain profile

Software Engineering

entity-profile:software-engineering@1.0 gives software repositories, source code, applications, algorithms, libraries, build artifacts, test evidence and engineering-control DCOs an explicit domain context inside the one ENTITY Global Passport system.

Authority boundary: installing or composing this profile does not create ownership, certification, regulatory status or economic rights. Rights remain governed by the DCO Rights Passport and applicable ENTITY authority.

Wallet migration

On 2026-10-03, ten legacy ENGINEERING_CONTROL DCOs that previously carried only the Global profile received new immutable Global Passport versions including Software Engineering. Prior passports, DCO IDs, controllers, Rights Passports, evidence, provenance and economic state were preserved.

Qualified result: the current BTG wallet snapshot resolved 10 assets to Software Engineering and 2 to Robotics, with zero missing domains.

Economic boundary

Domain classification does not authorize instrument actions. Economic instruments may contain only a subset of actions already authorized by the active DCO Rights Passport. The canonical market registry enforces that condition fail closed.
