Recipe 5

Initialize BTDU, ingest a pinned repository and reconstruct exact bytes

Run from the ENTITY repository root and use disposable state paths. The BTDU CLI requires a valid ENTITY state, BTDU state and the pinned ADAM runtime.

Initialize and verify state

python tools/entity_btdu_cli.py \
  --entity-state .recipe-state/entity \
  --btdu-state .recipe-state/btdu \
  --adam-root src/11_ADAM/full_runtime \
  --git-bin git \
  init

python tools/entity_btdu_cli.py \
  --entity-state .recipe-state/entity \
  --btdu-state .recipe-state/btdu \
  --adam-root src/11_ADAM/full_runtime \
  --git-bin git \
  status

Ingest a repository at an immutable commit

git -C PATH_TO_REPO rev-parse HEAD

python tools/entity_btdu_cli.py \
  --entity-state .recipe-state/entity \
  --btdu-state .recipe-state/btdu \
  --adam-root src/11_ADAM/full_runtime \
  --git-bin git \
  ingest-repo PATH_TO_REPO \
  --provenance git://owner/repository@EXACT_COMMIT

Save the returned repository manifest/object reference and atomic root.

Inspect bounded context

python tools/entity_btdu_cli.py \
  --entity-state .recipe-state/entity \
  --btdu-state .recipe-state/btdu \
  --adam-root src/11_ADAM/full_runtime \
  context OBJECT_REF

Reconstruct and hash

python tools/entity_btdu_cli.py \
  --entity-state .recipe-state/entity \
  --btdu-state .recipe-state/btdu \
  --adam-root src/11_ADAM/full_runtime \
  reconstruct OBJECT_REF reconstructed.bin

python -c "import hashlib,pathlib; p=pathlib.Path('reconstructed.bin'); print(hashlib.sha256(p.read_bytes()).hexdigest())"
Qualification rule: do not bypass an authorization, signature, root or reconstruction mismatch. A failed verifier is a failed operation.
