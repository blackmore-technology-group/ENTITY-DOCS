Operator manual

Rights Passport Operations

Issue

Confirm the issuing Entity has authority over the right; identify object, holder/controller, scope, restrictions, duration/quantity/jurisdiction, delegation/transfer rules and evidence; canonicalize and sign.

Verify before use

Check issuer authority, current status, expiry/revocation, requested action against scope and any usage/quantity constraints.

Delegate/transfer

Do not broaden the right. Preserve issuance/transfer provenance and apply explicit economic participation terms where they exist.

Use

Record the usage EVENT and link it to the passport/right. If usage triggers a settlement or derivative term, create the corresponding economic evidence rather than inferring value from access alone.

Revoke/supersede

Preserve the historical passport and create a revocation/supersession state/event. Historical verification and current permission are separate questions.
