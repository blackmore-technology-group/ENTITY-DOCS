ENTITY itself · core curriculum

Learn ENTITY from the primitives outward

This is the primary ENTITY tutorial track. It teaches the system itself—not the external contribution campaign. The Vector, Memnox and AWS work remains useful as real-world evidence, but it is a case study after you understand the core fabric.

ENTITY → AUTHORITY → RIGHT → EVENT → VALUE

Everything else in the platform composes around those primitives: governed objects, authority delegation, machine-readable rights, evidence and trust, encrypted information, BTDU topology, deterministic ADAM state, bounded NIKI reasoning, passports, privacy controls, global/offline topology, market execution, settlement and provider-independent recovery.

Learning rule: every tutorial asks the same questions: What exists? Who may act? What right exists? What event occurred? What evidence supports it? What value or obligation followed? Can the state be recovered without silently changing authority?
