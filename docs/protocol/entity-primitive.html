ENTITY

ENTITY is the persistent identity root to which authority, rights, events, evidence and value state can be related. It is intentionally separate from an account, device, host, provider or application.

Required properties

  • Stable identifier and verifiable manifest.
  • Explicit verification methods and key lifecycle.
  • Recovery continuity that preserves the same identity root.
  • Authority delegation rather than implicit control by infrastructure.
  • Portable interpretation across conforming implementations.

What ENTITY is not

Registration is not ownership; possession is not authority; hosting is not sovereignty. A service may store or route an Entity's records without becoming that Entity.

v3.4.2 canonical distinction

User Entities remain sovereign from protocol origin. Separately, canonical ENTITY protocol status preserves the Shawn Blackmore → Blackmore Technology Group → ENTITY → release lineage. Canonical protocol ancestry does not transfer user asset ownership to BTG.
