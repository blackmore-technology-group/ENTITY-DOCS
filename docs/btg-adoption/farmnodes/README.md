# FarmNodes: research environments, not merely folders

A **FarmNode** is a planned logical research identity that can be assigned a problem domain, tools, permitted data, bounded computing resources and evidence requirements. The architecture is meant to support an open-ended range of research types, including robotics, environment, agriculture, materials, software and authorized consumer research.

## From activity to a qualified product

1. The owner and source restrictions authorize the input.
2. An approved research task defines the question, permissible tools, resource budget and success criteria.
3. The farm records transformations, provenance, tests and failure cases.
4. An independent qualification stage evaluates output validity and potential privacy leakage.
5. Only assets satisfying explicit release criteria can proceed to rights and commercial review.

A qualified output might be a verified trend report, synthetic data set with tested disclosure risk, reusable DataChip, executable prediction method or industrial research finding. The raw inputs need not be transferred to buyers.

## Isolation and verification

Independent FarmNodes require substantive runtime isolation, access separation, signed owner authorization and clear evidence of which task ran on which environment. A registry containing thousands of farm definitions is not evidence of thousands of independently running laboratories.

NIKI's autonomous invention cycle must retain failures and repair attempts, including negative test results. Repeated test passes against familiar examples do not alone demonstrate original invention or production safety. Reproducibility, independent challenges, resource accounting and independent participants matter.

## Commercial readiness

A farm-produced asset is not market-ready merely because it has a file identifier. Rights provenance, reproducible tests, market relevance, quality metrics, disclosure-risk assessment and truthful public documentation precede any offering.
