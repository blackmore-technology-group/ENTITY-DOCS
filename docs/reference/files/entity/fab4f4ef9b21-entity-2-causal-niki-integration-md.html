# ENTITY 2.0 — Causal NIKI integration

ENTITY 2.0 development adds a bounded causal-intelligence layer to NIKI while preserving the authority boundary between ENTITY, ADAM, BSIE and NIKI.

## Responsibility boundary

- **ENTITY** remains the sovereign source of identity, authorization, rights, policy and delegated capability.
- **ADAM** remains the deterministic evidence/state-transition and governed execution substrate.
- **BSIE** remains authoritative for spatial/world state.
- **NIKI** reasons over bounded projections and may perform structural causal analysis, hard interventions and counterfactual comparison. It does not authorize or execute sovereign mutation.

## Causal intelligence

The public reference exposes `src/10_NIKI/causal_intelligence.py`. It supports explicit structural models, topological validation, bounded deterministic equations, hard `do`-style interventions, counterfactual recomputation and objective ranking.

Causal equations are data, not executable Python. Supported equation families are intentionally bounded. Cyclic models and unknown intervention targets fail closed. Persisting a causal model requires an explicit ENTITY approval record; NIKI cannot activate a persistent model by itself.

Counterfactual output is explicitly model-dependent analytical evidence. It is not proof that the modeled relationship is causal in the real world, and it grants no authority to act.

## Adaptive cognition routing

`src/10_NIKI/cognition_router.py` selects bounded reasoning stages according to request intent, available ADAM evidence, spatial requirements, application-owned domain signals, conflict, uncertainty, risk and whether a causal model is available.

Routing can activate deterministic reasoning, ADAM evidence reasoning, BSIE spatial reasoning, application-domain reasoning, causal/counterfactual reasoning and qualified critique. Routing never changes the authority model: ENTITY authorizes and ADAM executes governed actions.

## Deliberate exclusions

The ENTITY 2.0 NIKI integration does not import the legacy CGSI-SI voice/TTS stack, emotional companion/personality, avatar/HUD, unsupported superintelligence scoring, legacy certification claims, arbitrary executable causal equations, automatic source-code mutation, or duplicate sovereignty/policy systems.

BSIE trail datasets and application-domain corpora are not imported into ENTITY 2.0. Spatial/world data remains an external BSIE responsibility and is not an ENTITY release dependency.

## Qualification boundary

Internal software regression demonstrates the implementation and authority boundaries. Real-world causal validity still depends on the quality, provenance and independent validation of each domain causal model and its evidence. ENTITY 1.0 remains frozen and its sealed conformance kit remains unchanged.
