Build the digital-economic fabric

ENTITY is built around five primitives—ENTITY, AUTHORITY, RIGHT, EVENT and VALUE—and composes them into governed information, market execution, economic participation, causal lineage and provider-independent recovery.

Current runtime: ENTITY v3.4.3. The BTDU component remains 3.4.2 unchanged. Sovereignty is a system invariant; developers should treat the authority, information, exchange, economics and recovery layers as the complete platform.

Five primitives

PrimitiveDeveloper question
ENTITYWhat persistent actor, asset, dataset, software, model, device or financial object exists?
AUTHORITYWho may act, sign, access, execute, purchase, license, settle, publish, resolve, delegate or control?
RIGHTWhat may the holder inspect, read, copy, derive, train, infer, execute, modify, redistribute, commercialize, control or transfer?
EVENTWhat state transition, usage, provenance, market action or evidence event occurred?
VALUEWhat potential, offered, contracted, accrued, settled or realized consequence is actually supported?
