Profile Registry

The Global Passport profile registry provides versioned, reviewable context/constraint definitions. Profiles can describe jurisdictional, industry, privacy, trust or technical requirements without becoming a new authority system.

Registry responsibilities

  • Stable profile identifier.
  • Explicit version.
  • Schema/constraint definition.
  • Issuer/steward metadata and signature where required.
  • Compatibility/supersession information.
  • Mappings to external standards with mapping version.

Historical interpretation

A passport references the profile version that was used at issuance. Updating the registry must not silently reinterpret old signed passports. Supersede or migrate explicitly.

Fail closed

If a required profile cannot be resolved or a profile version is unsupported, verification should fail or return an explicit indeterminate/unsupported result rather than guessing.

Authority boundary

Registering a profile does not grant authority over users or assets. Profiles constrain an already-authorized workflow.
