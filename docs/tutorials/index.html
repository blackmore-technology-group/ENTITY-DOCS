ENTITY Tutorials

The primary tutorial track follows ENTITY's actual architecture—not the external contribution campaign. Start with the five primitives, learn authority and rights, govern real information and evidence, understand BTDU/ADAM/NIKI, then move into passports, privacy, distributed operation, economics and recovery.

ENTITY → AUTHORITY → RIGHT → EVENT → VALUE
Current runtime: ENTITY v3.4.3 with BTDU component 3.4.2. The tutorial layer preserves the same boundaries as the implementation: custody is not authority; access is not ownership; provenance is not truth or automatic royalty; AI inference does not mint rights; trade is not verified payment; recovery does not create missing authority or evidence.
