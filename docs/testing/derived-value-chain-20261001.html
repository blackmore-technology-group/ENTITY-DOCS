ENTITY test 19 | derived-output economy | 2026-10-01

Derived-output value chain

This test closes the causal loop from source data to a concrete derived object and then to explicit synthetic economic participation.

Claim boundary: source contribution weights and CAD-denominated amounts are declared synthetic test inputs. The test proves protocol behavior, provenance propagation and economic-record construction; it does not prove universal attribution truth, actual cash movement, market demand, fair market value or legal entitlement.

What was executed

  1. Created two independent source DCOs with separate originators.
  2. Each originator explicitly granted the developer TRAIN and DERIVE rights.
  3. The developer generated two signed AUTHORIZED_USE events before derivation.
  4. ENTITY created an actual MODEL object as the derived output.
  5. Two TRAINED_FROM provenance edges attached the source DCOs to that model at declared 60/40 contribution weights.
  6. contribution_distribution() distributed a synthetic 50,000-unit derived gross basis as 30,000 / 20,000.
  7. Each source originator had an explicit 10% derivative-participation policy, producing 3,000 / 2,000 obligations.
  8. Both 5,000 total obligations were settled using signed synthetic settlement attestations.
  9. An attempted reverse provenance edge that would create a cycle was rejected fail-closed.

Developer significance

This is the direct data-economy chain: data rights → authorized use → derived output → causal provenance → contribution allocation → explicit economic participation → settlement attestation. ENTITY does not invent value merely because provenance exists. The economic obligations arise because the source originators defined explicit derivative-participation policies.
