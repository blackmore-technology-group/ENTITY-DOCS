Global Passport

Layer boundary: Global Passport is later ENTITY runtime architecture. It is not an additional requirement for the frozen Protocol 1.0 clean-room campaign.

Global Passport is a portable runtime envelope that brings together an ENTITY identity/state context, rights, evidence, provenance and versioned context profiles without creating a second sovereign identity root.

Composition

identity/state → rights → evidence → provenance → profile stack → mappings → signed passport

Profile rule

Profiles constrain or contextualize interpretation. They do not manufacture authority. A healthcare profile cannot grant clinical authority merely because it is selected, and a finance mapping cannot make an instrument legally valid merely because it maps to an external standard.

Historical versions

A signed passport retains its referenced profile/mapping versions. Later software should interpret historical signed records under the applicable original semantics rather than silently rewriting them.

BTDU relationship

The Blackmore Technology Data Universe (BTDU) can provide runtime information topology/evidence references beneath a passport, while authority and rights remain governed by ENTITY runtime semantics. BTDU remains component version 3.4.2 unchanged in ENTITY v3.4.3.
