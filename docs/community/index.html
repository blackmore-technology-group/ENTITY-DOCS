Evidence discipline

Say what kind of result you actually have.

IMPLEMENTED → LOCALLY TESTED → BTG-QUALIFIED → EXTERNALLY REPRODUCED → INDEPENDENTLY IMPLEMENTED / VALIDATED → UPSTREAM ACCEPTED → ECONOMICALLY SETTLED

These states are intentionally separate. A local PASS is not independent validation. An upstream merge is not payment. Provenance is not ownership. A Discussion consensus is not a protocol change.

Community standards

Technical disagreement is welcome; personal attacks are not.

Critique implementations, claims and evidence. Reproducible failures, counterexamples and incompatible interpretations are useful contributions. Respect privacy and security boundaries and distinguish implemented, tested, qualified, experimental and proposed work.
