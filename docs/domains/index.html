Domain Packages

ENTITY uses six public domain-package repositories plus the built-in Software Engineering profile/package to map the same ENTITY fabric—identity, delegated authority, rights, evidence, governed events, economic state, recovery and portable passports—into operational domains. Where a domain uses markets, procurement, licensing, usage or settlement, the Exchange Protocol and economic-participation layers remain available rather than disappearing behind an identity-only profile.

Domain packages map to external standards and deployment facts; they do not redefine those standards or prove regulatory/legal compliance by themselves.
