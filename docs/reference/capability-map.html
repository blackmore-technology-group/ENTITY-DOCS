Canonical system map · ENTITY v3.4.3

ENTITY is a digital authority, information, market, economic, evidence and recovery fabric.

This page is the canonical high-level capability map for the current ENTITY runtime. It exists to prevent the system from being reduced to a sovereignty, identity or provenance stamp. Sovereignty protects continuity of authority and state across providers; the implemented system is broader.

ENTITY → AUTHORITY → RIGHT → EVENT → VALUE

Governed objects and actions

ENTITY can represent persistent governed actors and objects including people, organizations, AI agents, datasets, documents, models, software, APIs, devices, vehicles, buildings, research, digital twins, financial instruments and physical assets.

Authority actions include acting, signing, data access, execution, purchase, licensing, settlement, publishing, resolution, delegation and control. Rights actions include inspection, reading, copying, derivation, training, inference, execution, modification, redistribution, commercialization, control and transfer.

Claim boundaries

Do not collapse these states: sovereignty is not the whole product; hosting/custody is not authority; provenance is not automatically ownership or objective truth; upstream acceptance is not payment; a trade is not verified external settlement; economic observation is not automatically accounting fair value; AI inference does not mint rights; and BTG-controlled qualification is distinct from unrelated independent validation.
