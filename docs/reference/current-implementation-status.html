Operating rule

Pin immutable release tags for released semantics; pin an exact main commit for post-tag functionality. Verify reconstructed content before removing a source, preserve backups, and never interpret registration, signatures, claims or market indicators as proof of legal ownership, external-world truth, cash payment or certification.

Documentation boundaries

The frozen ENTITY Protocol 1.0 conformance kit is a separate normative target. Historical v3.4.1/v3.4.2 campaigns, signed manifests, test receipts and published hashes remain unchanged. This portal page and the linked repository status matrix are explanatory, not a new protocol version or independent audit.
