ENTITY Code Tutorials

These tutorials execute real ENTITY code against the pinned source commit. Each page includes the exact source file and a recorded terminal run; tutorials 6-13 also include an embedded browser-safe terminal replay.

Verification baseline: ENTITY commit 5be325437a63c2efaee0dc3caaae9ab0cd0773d9. Generated IDs and hashes vary; documented PASS/BLOCKED invariants must remain stable.

How to use these examples

  1. Use a current ENTITY checkout.
  2. Set ENTITY_ROOT.
  3. Use disposable state only.
  4. Run the example and compare invariant results.
  5. If a negative control unexpectedly succeeds, stop and investigate.
