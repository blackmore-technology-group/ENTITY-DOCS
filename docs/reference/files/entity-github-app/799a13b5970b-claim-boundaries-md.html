# Claim Boundaries

Every evidence candidate generated by this app carries the following invariant boundary:

- it asserts only an observation received from/configured against GitHub;
- it does not establish legal ownership or intellectual-property title;
- it does not establish objective truth of repository content;
- it does not establish independent validation merely because a check, workflow or implementation passed;
- it does not establish regulatory approval, security certification, market adoption or accounting value;
- it does not modify ENTITY semantics.

## CI and security results

A GitHub Actions, CodeQL, dependency or other check result is evidence of the named check at the identified repository state and time. Scope, configuration, tool limitations and operator independence remain separate questions.

## Authorship

Git commit/PR authorship metadata is evidence of GitHub/Git attribution. It must not be converted automatically into legal copyright ownership, employment status, assignment, contribution percentage or economic participation.

## Releases

A GitHub release/tag can identify a published engineering artifact. It does not by itself establish product authorization, customer availability, contractual support, legal rights or commercial release approval.
