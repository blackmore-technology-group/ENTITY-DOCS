# Support

Support contact: `blackmore.technology.group@gmail.com`

For reproducible defects, include the app version, Python version, operating system, GitHub event type, sanitized error text and the relevant evidence candidate/audit identifier. Do not include secrets, private keys, access tokens or confidential repository payloads.

Security vulnerabilities should follow `SECURITY.md` rather than a public issue.
