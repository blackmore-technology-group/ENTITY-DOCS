Protocol primitive 3/5

RIGHT

RIGHT represents a permission, entitlement, restriction or retained interest connected to an object or activity. It is not inferred from possession of bytes.

Possible dimensions

Access, inspect, query, train, derive, redistribute, sublicense, commercialize, exclude, use for a duration, use in a jurisdiction, consume a quantity/capacity, receive revenue participation or transfer/delegate subject to constraints.

Lifecycle

issue → verify → delegate/transfer if permitted → exercise → record EVENT → settle obligations

Non-rival data

Because identical data bytes can exist in multiple places, ENTITY places scarcity in rights/entitlements rather than pretending every copied byte is a unique physical object.

Boundary

BTDU relationships never create a right merely because two nodes are connected. Economic participation requires explicit terms.
