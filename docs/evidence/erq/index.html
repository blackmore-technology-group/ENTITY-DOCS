Rights boundary

Custody is not ownership.

UPSTREAM OWNERSHIP ≠ BTG FORK CUSTODY ≠ BTG ENTITY METADATA OWNERSHIP ≠ ENTITY PROTOCOL ORIGIN ≠ AUTOMATIC ECONOMIC RIGHTS

ENTITY records the upstream source, history, licence and provenance while BTG separately owns or controls only the derived verification/provenance metadata it creates. Ingestion does not create ownership or automatic economic entitlement.
