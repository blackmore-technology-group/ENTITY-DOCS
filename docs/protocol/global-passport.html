Protocol semantics

Global Passport

The Global Passport is one portable envelope for existing ENTITY identity, rights, evidence and provenance. It can carry a composable stack of versioned context profiles without creating a new sovereign root.

Composition

identity/state → rights → evidence → provenance → profile stack → mappings → signed passport

Profile rule

Profiles constrain or contextualize interpretation. They do not create authority. A healthcare profile cannot grant clinical authority merely because it is selected; a finance mapping cannot make an instrument legally valid merely because it maps to ISO/FIX fields.

Historical versions

A passport retains its referenced profile/mapping versions. Current software must be able to interpret historical signed records according to their original semantics rather than silently applying new rules.

BTDU relationship

BTDU may provide the information topology/evidence references beneath a passport, but the passport remains governed by ENTITY authority/rights semantics.
