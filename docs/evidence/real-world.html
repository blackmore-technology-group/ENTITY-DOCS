Designed for scale

The same path works for the next contribution and the hundredth.

New public records under ENTITY/evidence/bounty/ are discovered automatically. The ledger selects the latest published record for each external repository/issue pair and enriches it with live GitHub state. A bootstrap entry exists only for the first Vector proof until its local evidence directory is pushed into the ENTITY repository; a real ENTITY evidence file supersedes the bootstrap automatically.

Bounty work

Funded and promised work can be shown without treating an advertised amount as settled revenue. Settlement remains a separate evidenced event.

Pro-bono work

Zero-dollar contributions can accumulate externally verifiable provenance, review, CI, merge and downstream history while realized cash correctly remains zero.

Downstream reuse

Git ancestry can later be connected to forks and derivatives where evidence supports the relationship. Similar code alone is not represented as proven descent.

Rights boundary: ENTITY provenance records contribution history; it does not convert an upstream project's source into BTG-owned property or override the applicable open-source licence.
