Standards Mapping

ENTITY mappings connect protocol/passport fields to external standards so systems can interoperate without claiming ENTITY replaces or redefines those standards.

Current public mapping examples

DomainMappings
HealthcareHL7 FHIR, DICOM
FinanceISO 20022, FIX, LEI
ManufacturingOPC UA, Asset Administration Shell
AINIST AI RMF, SPDX 3, CycloneDX
RoboticsROS 2, Open-RMF
Defence/Public-UnclassifiedPublic Data Governance, Originator Control

Mapping record

Record ENTITY field/concept, external standard/version, external field/concept, transformation/cardinality rules, limitations and mapping version. If an external standard changes, publish a new mapping version.

Boundary

A mapping that says an ENTITY field corresponds to a FHIR/ISO/FIX field does not certify compliance with the external standard or regulator.
