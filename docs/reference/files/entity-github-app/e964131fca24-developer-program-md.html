# GitHub Developer Program Readiness

## Project status

ENTITY GitHub App v0.1 is an integration in active development using the GitHub API. The source repository, support contact, GitHub App authentication implementation and read-only API client form the technical basis for Developer Program registration.

Support contact: `blackmore.technology.group@gmail.com`

## Claim boundary

This document records project readiness only. It must not state that Blackmore Technology Group or the authenticated GitHub account is a GitHub Developer Program member until GitHub confirms registration and the account/profile reflects that state.

Program membership does not mean GitHub developed, audited, certified or endorsed ENTITY or this integration.

## Registration evidence to retain

When registration is completed, retain the confirmation date, registered account, support contact, GitHub App identity, applicable terms/version and a screenshot or GitHub-issued confirmation reference in BTG's software-release evidence package. Do not store the GitHub App private key or webhook secret in that evidence package.
