The economic lineage

Contribution history is an economic primitive even before a price exists.

EXTERNAL PROBLEM → CONTRIBUTOR → CHANGE-SET → VALIDATION → UPSTREAM ACCEPTANCE → ENTITY / BTDU LINEAGE → ECONOMIC STATE → OPTIONAL INSTRUMENT → OPTIONAL SETTLEMENT

Problem and contributor

The outside issue and BTG contributor remain attributable instead of being reduced to an anonymous code artifact.

Exact technical consequence

Commits, tests, reviews, CI/security and accepted upstream state provide evidence that a specific contribution was independently adopted.

Economic state without fiction

A contribution can be pro bono, contingent, funded or settled. Upstream merge does not automatically become a payment or monetary valuation.

How this fits the full ENTITY economy

The contribution cases feed a much larger implemented market fabric.

ENTITY's exchange/recovery layers implement the state required for venues, rights-based instruments, balances, listings, disclosures, order books, call auctions, RFQs/quotes/acceptances, trades, clearing, entitlements, usage, surveillance, cancellations, revenue rules/rule sets, trade-revenue bindings, authorized settlement verifiers and payment attestations.

DCO → INSTRUMENT → LISTING → DISCLOSURE → ORDER / RFQ / AUCTION → PRICE DISCOVERY → TRADE → CLEARING → SETTLEMENT → ENTITLEMENT → USAGE → DERIVED OUTPUT → ECONOMIC CONSEQUENCE

A contribution can become an instrument

CONTRIBUTION is an implemented Exchange Protocol instrument class. If valid rights and terms exist, a contribution history can later be referenced by a rights instrument, contract, service or participation policy.

The original history does not change

Later commercial terms bind to the accepted lineage; they do not retroactively turn an open-source merge into proprietary ownership or pretend a payment existed before settlement evidence.

Causal economic attribution

ENTITY can trace from contribution to later consequence only when evidence supports the edges.

CONTRIBUTOR → SOURCE / DCO → RIGHT / LICENSE → USAGE → DERIVED ASSET / PRODUCT → TRANSACTION → REVENUE → SETTLEMENT

Economic attribution is evidence-bound and acyclic. A market observation is not automatically accounting fair value, and protocol records do not determine legal entitlement by themselves.

Rights boundary: ENTITY records contribution history; it does not override an upstream licence, manufacture ownership, invent a royalty, or turn upstream acceptance into a debt.
