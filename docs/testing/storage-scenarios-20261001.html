Developer storage scenario suite

Six fresh, video-recorded scenarios map the storage advantage envelope instead of presenting one universal compression number.

Read this first: positive reduction means the measured ENTITY representation is smaller than the named baseline. Negative reduction means ENTITY is larger. These are workload-specific engineering measurements.

What developers should take away

  • Repeated structured facts: current-state factoring is consistently strong in these tests.
  • Mixed data: savings narrow as value diversity rises.
  • Unique/high-entropy data: factoring can expand storage substantially.
  • Vector comparisons: the 4.4 GB Level-3 representation crosses a float32-per-entity vector baseline at 22 dimensions.
  • History/provenance: retained temporal evidence can dominate storage; compare it to current-state databases only with that semantic difference stated.
  • Known v0.41 temporal-cycle limitation: repeated logical bond identities can lose an earlier interval; tracked in ENTITY #116.
