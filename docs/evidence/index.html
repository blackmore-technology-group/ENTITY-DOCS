Evidence ladder

Not every pass, merge or receipt proves the same thing.

1 · BTG-controlled qualification

Tests executed against code/campaigns controlled by BTG. Engineering evidence—not unrelated validation.

2 · External reproduction

An unrelated person independently runs a published BTG baseline and reports environment, results and hashes.

3 · External real-world consequence

An unrelated upstream project reviews/tests/accepts BTG work, providing externally controlled evidence of technical adoption.

4 · Independent implementation

An unrelated implementer builds from public protocol/conformance material using a repository and architecture they control.

5 · Independent security / standards review

Outside reviewers control methodology and report boundaries, incompatibilities or findings.

6 · Institutional/commercial use

Organizations exercise the system against real operational, market or integration requirements with independently controlled evidence.
