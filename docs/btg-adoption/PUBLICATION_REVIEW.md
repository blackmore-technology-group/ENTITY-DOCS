# Publication approval checklist — BTG Documentation and Adoption Portal

- [ ] Confirm BTG owner-approved external release of every document and approved use of the supplied BTG icon
- [ ] Privacy review; no third-party sensitive records or unconsented activity disclosed
- [ ] Copyright and source review
- [ ] Securities counsel approval for any investment / exchange language that could imply solicitation
- [ ] Verify technical status against exact time-stamped engineering evidence
- [ ] Review all outbound factual citations and platform-rights representations
- [ ] No private Exchange scripts, registry internals, instrument listings, ledgers, credentials or secrets
- [ ] Confirm published URLs, mobile render and link integrity
- [ ] Attach dated release approver and correction contact before institutional distribution

This document is a checklist, **not** evidence that the gates have been approved.
