Tutorials

These walkthroughs bridge the gap between architecture and actual use. Start with an Entity identity, put real bytes under governed BTDU state, follow a rights instrument through the market lifecycle, prove recovery, then connect an external contribution to verifiable lineage.

Current runtime: ENTITY v3.4.3 with BTDU component 3.4.2. Tutorials preserve the same claim boundaries as the protocol: authority is not hosting, provenance is not automatically ownership, trade execution is not external payment, and recovery does not create missing rights or evidence.

Core learning path

1 · Create & sign with an EntityCreate an ent2- identity, verify its manifest, sign a payload and understand operational versus recovery keys.2 · Ingest & reconstruct with BTDUInitialize state, ingest a pinned Git repository, inspect governed context and reconstruct exact bytes.3 · Walk through a rights marketMove from governed object to rights instrument, listing, order/RFQ/auction, trade, settlement evidence, entitlement and usage.4 · Run a recovery drillVerify that identity, BTDU and economic state survive provider/workspace loss without silently expanding authority.5 · Record contribution lineageUse the Vector and Memnox pattern to separate authorship, upstream acceptance, rights context and economic settlement.
