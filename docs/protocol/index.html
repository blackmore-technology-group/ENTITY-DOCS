Runtime Architecture & Semantics

The current runtime is a governed digital-economic fabric built from five primitives and composed into authority, rights, evidence, information, market execution, participation, causal lineage and recovery. Sovereignty is one of its invariants, not a synonym for the system.

Protocol boundary: this section explains the current ENTITY runtime family. Independent Protocol 1.0 clean-room work still uses the separately sealed conformance material. ENTITY v3.4.3 is the current runtime; BTDU remains component 3.4.2 unchanged.

The layers interoperate, but their claim boundaries remain separate. A platform can implement a market capability that one particular external evidence case has not yet exercised; a merged contribution can prove acceptance without proving payment; and a valid signature can prove attribution without proving external-world truth.
